Carnivor's Corner

CATEGORY Web Development / E-commerce
ROLE Team Leader
YEAR 2024
STACK PHP · MySQL · JavaScript

Carnivor's Corner is a full-stack e-commerce website built for selling meat and marinated products online. As team leader, I directed the build and wrote a meaningful share of the code myself.

Customers can browse products, manage a cart and wishlist, place orders, and process simulated payments. On the other side, an admin dashboard handles products, inventory, customers, orders, promotions, and sales reports.

The project paired a PHP and MySQL backend with a hand-built HTML/CSS/JavaScript frontend, including a secure authentication system for both customers and admins.

PHP MYSQL HTML CSS JAVASCRIPT
KEY FEATURES
  • Cart, wishlist, and simulated checkout flow
  • Secure customer and admin authentication
  • Admin dashboard for inventory and sales reports
  • Promotions and order management tools
