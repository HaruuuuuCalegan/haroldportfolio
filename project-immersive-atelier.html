Immersive Atelier

CATEGORY VR / Interactive
ROLE Game Developer
YEAR 2026
STACK Unity · C# · Blender

Immersive Atelier (PIA) is a virtual reality educational game that teaches the pottery-making process through interactive simulation. It was built with Unity and C# for VR headsets.

The core of the project is a 3D mesh modeling algorithm that simulates clay shaping and trimming in real time as the player's hands move, alongside guided tutorials, pottery challenges, decoration tools, firing simulations, measurement feedback, and a performance evaluation system.

The goal was to make a genuinely hands-on craft feel tactile and teachable in VR, rather than just a passive walkthrough.

UNITY C# VIRTUAL REALITY BLENDER
KEY FEATURES
  • Real-time 3D mesh deformation for clay shaping
  • Guided pottery tutorials and challenges
  • Firing simulation with scoring feedback
  • Natural VR hand-tracking interactions
